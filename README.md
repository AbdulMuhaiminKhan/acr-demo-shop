# acr-demo-shop

A tiny Flask shop used to demo [Agentic Code Reviewer](https://github.com/AbdulMuhaiminKhan/Agentic-Code-Reviewer).

**The pull requests in this repo contain intentionally vulnerable code** (SQL injection, open redirect, path traversal,
command injection, a swallowed exception). Don't deploy it or copy from it.

Each open PR carries an automated review comment written by a local `qwen2.5-coder:7b` model:

| PR | Planted | Reviewer |
|---|---|---|
| #1 | SQL injection, open redirect after login | caught the SQL injection, missed the open redirect |
| #2 | path traversal, `except Exception: pass` | caught both |
| #3 | command injection (`shell=True`), untested helper | caught both |
| #4 | nothing (clean refactor with tests) | "Looks good" |

Generated by `examples/build_demo_prs.py` in the reviewer's repository.
